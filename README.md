# StudyNotes Hub — Student Notes Website

## About the Project
StudyNotes Hub is a student notes website designed to help students find and study educational notes easily. It provides a simple and user-friendly experience for students.

## Project Type
Generative AI Assignment — Assignment 01

## AI Tool Used
Lovable AI

## Features
- Clean and modern website design
- Subject sections for different study areas
- Notes library for educational resources
- Search functionality to find notes easily
- Responsive design for mobile and desktop
- Cookie consent popup
- Easy navigation

## Technologies Used
- TypeScript
- Web development tools and frameworks used in the project

## Learning and Reflection
Through this project, I learned how to use an AI website builder to develop a website. I also learned about website structure, user-friendly design, and managing project files on GitHub.
